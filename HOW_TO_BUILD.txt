================================================================================
  PANN POS System - How to Build the Executable
================================================================================

WHERE TO RUN:
-------------
Open Command Prompt (cmd) or PowerShell in this folder:
  C:\Users\ngjam\Desktop\PANN_POS_SYSTEM

METHOD 1: Double-Click (Easiest)
---------------------------------
1. Open Windows Explorer
2. Navigate to: C:\Users\ngjam\Desktop\PANN_POS_SYSTEM
3. Double-click: build.bat
4. Wait for build to complete
5. Find your .exe at: backend\dist\PANN_POS_System.exe

METHOD 2: Command Prompt
-------------------------
1. Press Win + R
2. Type: cmd
3. Press Enter
4. Type: cd C:\Users\ngjam\Desktop\PANN_POS_SYSTEM
5. Press Enter
6. Type: build.bat
7. Press Enter
8. Wait for build to complete

METHOD 3: PowerShell
---------------------
1. Press Win + X
2. Click "Windows PowerShell" or "Terminal"
3. Type: cd C:\Users\ngjam\Desktop\PANN_POS_SYSTEM
4. Press Enter
5. Type: .\build.bat
6. Press Enter
7. Wait for build to complete

WHICH BUILD SCRIPT TO USE:
---------------------------
build.bat                  →  Standalone executable only
build_with_installer.bat   →  Executable + Windows installer (needs Inno Setup)
CreateInstaller.ps1        →  PowerShell installer (no extra tools)

RECOMMENDED: Start with build.bat

WHAT HAPPENS WHEN YOU RUN build.bat:
-------------------------------------
✓ Builds Vue.js frontend
✓ Installs Python dependencies
✓ Packages everything into one .exe file
✓ Creates: backend\dist\PANN_POS_System.exe

HOW LONG IT TAKES:
------------------
First time: 5-10 minutes
After that: 3-5 minutes

AFTER BUILDING:
---------------
Your .exe will be at:
  C:\Users\ngjam\Desktop\PANN_POS_SYSTEM\backend\dist\PANN_POS_System.exe

Double-click the .exe to run your POS system!

ACCESS THE APP:
---------------
Once running, open browser and go to:
  http://localhost:8000
